# Security Policy

## Reporting a Vulnerability

DMNE Labs takes the security of `dmne-meme-alpha` seriously. If you discover a security vulnerability, please report it responsibly by emailing:

- **Security Contact:** `security@dmnelabs.com`

Please include:
- A clear description of the vulnerability and potential impact.
- Minimal steps or a proof-of-concept to reproduce the issue.
- Affected files or module paths.

Do not open public GitHub issues for undisclosed security vulnerabilities. We will acknowledge receipt and work with you on a coordinated remediation timeline.
